Site public du studio Games of Forge.

Statique, sans build, sans dependance : GitHub Pages sert les fichiers tels quels.

- Francais a la racine (`index.html`, `herd.html`, `pierre.html`)
- Anglais dans `en/`
- Style commun : `style.css` ; images : `assets/`

Cartes de partage (`assets/og.png`, `en/og.png`) regenerees par `Aethera/automation/scripts/gof-site-og.js`.
Captures de verification : `gof-site-shot.js` (telephone) et `gof-site-shot-desktop.js` (bureau).
Apercu local : `gof-site-serve.js` puis http://localhost:8099
