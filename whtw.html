The bet

Making an engine do what it never planned for

Warscape, the Total War engine, is closed: you touch neither the code nor the animations, only data and scripts. Third-person hero control is nowhere in its plans. The whole question is how far you can get with what is left, and where exactly the wall stands. Same name as TOR Fantasy Adventures, same itch, on an engine that has nothing to do with it.

What already runs

A playable skeleton validated in game in early July 2026: keyboard movement decoupled from camera movement, an over-the-shoulder camera, target lock, a dash and two abilities. It is nothing like a game yet, but it proves the fantasy stands up inside that engine.

What the engine refuses

No new animation, no mouse aiming. The cursor position cannot be read from Lua, in battle or in campaign, so real mouselook is out. The way around it is to never read the mouse and derive the hero's facing from the camera's, which can be read. A workaround entirely inside the engine.

L'Atelier

Building a character in a game that does not allow it

The furthest along part of the project is an authoring tool: assembling a hero and their equipment piece by piece, and seeing it immediately. Rather than building a custom preview window, which hit the same wall six times, the tool hijacks the game's own 3D panel. Out of roughly twenty thousand pieces catalogued in the data, a little over five hundred are usable in the forge today.

  • Preview The game's own detail panel, reused and made mouse-driven
  • Assembly Models composed on the fly and applied to the character without a restart
  • Colour Textures recoloured offline, for lack of an accessible tint shader
  • Pipeline Play, create in game, quit, run one script, relaunch: the whole cycle is a single command

Honestly

Nothing has shipped

No public build, no date, no promise. I show it here because this is where I do my searching, and because how you get around a closed engine probably says more about the way I work than a page of skills would. If it ever ships, it will be written on this page.
